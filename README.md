# Code Kids Adventure Lab

Code Kids Adventure Lab is a playful, browser-based learning experience designed to help children explore foundational coding ideas. Learners guide colorful characters through **60 interactive quests** spanning three skill areas:

- **Sequencing Lab** – 20 drag-to-order adventures that build step-by-step thinking.
- **Events & Conditions Lab** – 20 branching story puzzles that highlight cause and effect.
- **Looping Lab** – 20 rhythm and pattern challenges focused on repetition.

Each challenge includes vibrant illustrations, friendly hints, and celebratory sounds so young coders stay curious and motivated.

## Getting started

1. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
2. Keep `styles.css` and `app.js` in the same directory so the experience loads correctly.
3. (Optional) Launch a quick local server with `make run`, then visit [http://localhost:8000](http://localhost:8000).
4. Toggle sound on/off with the control in the upper-right corner.

> `make run` simply calls `python3 -m http.server 8000` so you can preview sounds and animations without disabling your browser's local file security settings. Use `Ctrl+C` in the terminal to stop the server when you're done exploring.

No build tools are required—everything runs offline from the static files in this repository.
